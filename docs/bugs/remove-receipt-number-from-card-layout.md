# Bug: Remove the Receipt Number from the Card Layout

## Problem

The receipt number is not important information for the card layout. It should be
removed from the expense card view.

## Reproduce

1. View expenses in the card layout.
2. **Result:** The receipt number is shown on the card.
3. **Expected:** The receipt number is not shown in the card layout.

## Suggested Solution

Remove the receipt-number field from the expense card layout.
