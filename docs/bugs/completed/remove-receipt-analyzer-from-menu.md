# Bug: Remove the Receipt Analyzer from the Menu

## Problem

The Receipt Analyzer entry should not be exposed in the navigation menu. It needs
to be removed from the menu.

## Reproduce

1. Open the navigation menu.
2. **Result:** "Receipt Analyzer" appears as a menu item.
3. **Expected:** It is not present in the menu.

## Suggested Solution

Remove the Receipt Analyzer menu entry (and any now-orphaned route/screen if it is
no longer reachable elsewhere).
