# Bug: Manager Navigation Menu — No Link to the Main Dashboard

## Problem

The manager navigation menu has no link to the main (manager) dashboard. A manager
who has navigated away has no menu entry to return to the main dashboard.

## Reproduce

1. Log in as a manager.
2. Open the navigation menu.
3. **Result:** There is no entry for the main dashboard.
4. **Expected:** A menu link that returns to the manager main dashboard.

## Suggested Solution

Add a navigation entry linking to the manager main dashboard (desktop menu + mobile
menu sheet).
