# Bug: User Dashboard (Mobile) — Missing Layout/Table Toggle

## Problem

On the user dashboard, the layout/table view toggle is missing on mobile. It is
available on desktop but not surfaced at mobile widths.

## Reproduce

1. Log in as an employee.
2. Open the user dashboard on a mobile (narrow) viewport.
3. **Result:** The layout/table toggle is not present.
4. **Expected:** The toggle is available on mobile too.

## Suggested Solution

Surface the layout/table toggle in the mobile layout of the user dashboard.
